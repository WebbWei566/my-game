## 一、遊戲定位

| 項目 | 決定 |
|---|---|
| 類型 | 修仙放置＋文字奇遇＋輕度 Roguelite 秘境 |
| 平台 | 手機直式優先，桌機也能玩（PWA，可安裝到主畫面） |
| 單次遊玩 | 1～5 分鐘碎片時間，支援離線收益 |
| 美術風格 | 水墨、留白、宣紙色調、書法字體（Ma Shan Zheng） |
| 世界觀 | **原創**：宗門、地名、人物自行設計，不使用現有小說設定 |

## 二、核心循環

```
打坐修煉（累積修為）→ 境界突破（大境界需渡劫）
      ↑                          ↓
煉丹／煉器（加速、提升）← 秘境探索（材料、功法、奇遇）
```

## 五、技術決策

| 項目 | 選擇 | 理由／備註 |
|---|---|---|
| 框架 | **Vue 3 + Pinia** | 遊戲以 UI 和狀態為主，Vue 響應式最省力（由我代選） |
| 語言 | TypeScript | 數值和存檔結構多，型別能避免 bug |
| 建置 | Vite | — |
| PWA | vite-plugin-pwa（Workbox） | 自動更新，Google Fonts 走 CacheFirst 離線快取 |
| 存檔 | idb-keyval（IndexedDB） | 失敗時退回 localStorage |
| 大數字 | **不使用** break_infinity.js | JS 原生數字可到約 1e308，目前夠用；做轉世系統時再評估 |
| 測試 | Vitest + happy-dom + fake-indexeddb | 執行 `npm test` |
| 部署 | **GitHub Pages**（GitHub Actions） | `BASE_PATH=/<repo>/` 由 CI 傳入 |
| 圖示 | @vite-pwa/assets-generator | 修改 `public/logo.svg` 後執行 `npm run icons` |

### 程式結構原則
- **資料驅動**：境界、靈根、奇遇放在 `src/data/`，加內容不用改邏輯
- **公式集中**：所有數值和 `BALANCE` 參數都在 `src/core/formulas.ts`
- **存檔有版本號**：改結構時要在 `src/core/save.ts` 的 `migrate()` 加遷移
